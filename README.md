# Невидимые истории — пилотная версия

Streamlit-прототип интерактивной цифровой выставки о скрытых формах семейного неблагополучия.

## Что доступно
- Первоначальная проверка восприятия (5 вопросов без немедленного показа правильных ответов)
- История Никиты: 4 сцены, 3 документа, карта невидимого, вывод
- «Невидимая статистика»: 4 экрана, российские и международные данные с пояснениями

Две другие истории и итоговое тестирование пока не реализованы. Данная версия не измеряет изменение знаний до и после выставки.

## Локальный запуск
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Публикация на Streamlit Community Cloud
1. Загрузить **содержимое этой папки** в отдельный репозиторий GitHub (не загружать `.venv`, резервные копии и файлы с секретами).
2. На https://share.streamlit.io выбрать создание нового приложения из GitHub.
3. Указать репозиторий, ветку `main`, файл `app.py` и Python 3.12 (если предлагается).
4. Убедиться, что приложение открывается по публичной ссылке в браузере без авторизации.
5. Отдельно отправить участникам ссылку на анкету обратной связи.

Текущая версия использует локальные изображения `assets/nikita/`. Интернет для их загрузки не требуется.

## Ограничения и этика
- Художественные изображения и история Никиты — реконструкция, не реальные материалы частной семьи.
- Психологическая агрессия, физические наказания, отношение к насилию и официальная регистрация — разные показатели; они не сопоставимы напрямую.
- В приложении не реализована база данных или отправка анкет. Ответы Streamlit хранятся только в состоянии сеанса и могут сброситься при обновлении/разрыве соединения.
- Тема может быть тяжёлой; участие добровольно, без требования раскрывать личный опыт.
