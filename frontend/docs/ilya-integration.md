> Актуальный режим — `full`: все три истории включены, статистика открывается после всех трёх. Текущие инструкции: [full-mode.md](full-mode.md). Ниже сохранено описание предыдущих этапов пилота.

Основа: `story-design-system`, `527f98a`. Источник художественного содержания — только `sources/ilya-scenario-4.0.docx`. Его SHA-256, исходные абзацы и соответствие фрагментам сохранены в `tests/fixtures/ilya-v4-source.json`.

## Локальный просмотр

Из папки `frontend`:

```powershell
npm.cmd run dev:ilya
```

Откройте адрес Local, напечатанный Vite. Этот запуск включает `VITE_ENABLE_ILYA_PREVIEW=1` только для текущего процесса. В `.env` ничего записывать не нужно. Не меняются настройки GitHub или Vercel.

На экране выбора появится служебная подпись локального тестирования. Пройдите Лизу и Никиту или продолжите сохранённый прогресс. После Никиты Илья доступен для тестирования. Статистика по-прежнему открывается после Лизы и Никиты независимо от завершения Ильи.

Обычный `npm.cmd run dev` / `npm.cmd run build` сохраняет прежний пилот с недоступной карточкой Ильи. Если в окружении уже задан `VITE_ENABLE_ILYA_PREVIEW=1`, удалите эту переменную для обычного запуска. Для сохранения прежнего sessionStorage используйте ту же вкладку и тот же адрес с портом.

Отдельная локальная сборка:

```powershell
npm.cmd run build:ilya
```

Она записывается в игнорируемую папку `dist-ilya-preview`, не подменяет стандартный `dist` и сама ничего не публикует. Семь утверждённых иллюстраций подключены из `public/assets/ilya/`. Режим остаётся локальным тестовым; переход в полную выставку отдельно не согласован.

## Содержание и порядок

1. Знакомство с героем.
2. «Последняя партия» — смешанная сцена: разговор, мысли, пропущенные вызовы, полная переписка и мысли.
3. «Дома поговорим».
4. «Как обычно».
5. Три материала в свободном порядке: 01 — Семейное застолье; 02 — Переписка с мамой; 03 — «А у вас не так?».
6. Карта с тремя вопросами, варианты и объяснения дословно; ключи B/C/A.
7. Объяснение четырёх факторов и полный абзац об ограничениях интерпретации настороженности.
8. `StoryClosing` с тремя исходными абзацами → экран выбора.

После разговора с Кириллом не добавлена новая художественная сцена. Свободный порядок и повторный просмотр материалов сохранены, поэтому пользователь может вернуться к любому из них.

Повествование, монологи и реплики хранятся явными `fragments` в исходной последовательности. Живые диалоги показывают одну текущую реплику; чат с отцом и чат с мамой показывают все сообщения одновременно. Пощёчина и защитная реакция передаются только исходными авторскими фрагментами: без новых эффектов, повторов, изображений удара или звука.

Служебное примечание DOCX о первоначальной проверке не возвращено в интерфейс. Исходник сохранён полностью; карта не вычисляет балл и не меняет исторические ответы теста. Итоговый тест и эпилог не реализованы.

## Общие компоненты и сохранения

`DialogueMaterial` использует существующие `Scene`, `SceneArtwork`, `LiveDialogue`, `MonologuePanel`, `SceneNavigation`. Последняя кнопка закрывает материал; переход к карте остаётся отдельным действием. Первая кнопка «Назад» на первом фрагменте возвращает к списку материалов.

Для диалоговых материалов `materialPositions` хранит текущий фрагмент, `reachedMaterialPositions` — максимальную достигнутую позицию. Материал считается изученным после достижения последнего фрагмента. До этого открытие само по себе не разблокирует карту. Переписка считается изученной при открытии, поскольку видна целиком. Материалы Лизы и Никиты продолжают работать по прежним правилам.

Схема состояния — версия 6. Принимаются версии 1–6, ключ `invisible-stories:pilot:v1` и `contentVersion: pilot-1` сохранены. Все утверждённые модули входят в реестр хранения, а `availableStoryIds` определяет доступ. Поэтому выключение локального тестирования не удаляет прогресс Ильи. Старые сеансы получают начальное состояние новой истории, без сброса Лизы, Никиты, статистики или исторических ответов.

`InvisibleMap` поддерживает необязательное поле `question`: Илья показывает точные индивидуальные вопросы, Лиза и Никита сохраняют прежние формулировки интерфейса.

Переход к полной выставке НЕ выполнен. Позднее потребуется отдельно согласовать включение Ильи по умолчанию и `mode: full`. Полный режим уже проверяет завершение всех трёх историй.
