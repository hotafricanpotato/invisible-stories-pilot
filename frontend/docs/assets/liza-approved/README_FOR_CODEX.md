# Лиза — утверждённые иллюстрации для Codex

Семь финально согласованных визуальных материалов для истории «Хорошая девочка», сценарий 2.0.
Все иллюстрации конвертированы из утверждённых PNG в WebP без изменения композиции, без добавления текста и без искусственного увеличения размера.

Файлы:
- `liza-introduction.webp` — Знакомство; Лиза с телефоном.
- `liza-after-performance.webp` — После выступления; утверждённый вариант 2.
- `liza-other-plans.webp` — Другие планы; новая кухня с ноутбуком и фотографиями.
- `liza-everything-fine.webp` — Всё нормально; вечерняя кухня.
- `liza-last-scene.webp` — Последняя сцена; Лиза за ноутбуком, без телефона.
- `liza-album-2019.webp` — Фотоархив 2019; утверждённый вариант 2, Лиза одна.
- `liza-album-2024.webp` — Фотоархив 2024; Лиза и мама.

ВАЖНО:
- Исторические фото 2019/2024 являются художественной реконструкцией вымышленного семейного архива. Рамка и бумажная подложка уже включены в картинки; избегать лишней двойной рамки в UI.
- Не заменять утверждённые сценарные реплики, сообщения, варианты ответов и порядок сцен. Текст и элементы интерфейса выводить через HTML, не впечатывать в иллюстрации.
- Для изображения `liza-last-scene.webp` не рисовать телефон; переписка с мамой должна выводиться отдельным HTML-компонентом в соответствии со сценарием.
- Для мобильного отображения использовать responsive CSS и проверять кадрирование. Отдельных мобильных экспортов утверждено не было. Нельзя обрезать лица.
- Настоящие размеры PNG/WebP указаны в `MANIFEST.csv`; некоторые исходники меньше ранее рекомендованных целевых 1920×1080. Не выдавать увеличенные копии за более детальные оригиналы.
- Не заменять существующую историю Никиты и не изменять статистику.
- Не выполнять push, merge или публикацию без согласия пользователя.
