# «Невидимые истории» — Илья, сценарий 4.0

Пакет из 7 **утверждённых пользователем** иллюстраций для интеграции истории Ильи в ветку `story-design-system`.

## Назначение

| Файл | Сцена |
|---|---|
| `ilya-introduction.webp` | Знакомство с Ильёй, отец даёт деньги на такси |
| `ilya-last-game.webp` | Последняя партия у Кирилла; утверждённый вариант с днём рождения |
| `ilya-home-conversation.webp` | Дома поговорим; поздний разговор в прихожей без изображения удара |
| `ilya-breakfast.webp` | Как обычно; отец готовит завтрак |
| `ilya-family-feast.webp` | Семейное застолье; три поколения |
| `ilya-mother-chat.webp` | Переписка с мамой; Илья с телефоном, без встроенных сообщений |
| `ilya-kirill-conversation.webp` | А у вас не так?; утверждённый вариант со светловолосым Кириллом |

## Требования при подключении

1. Подключить по идентификаторам сцен/материалов из `ilyaPresentation.js`, заменив соответствующие временные заглушки.
2. Сохранить HTML-текст, монологи и диалоги отдельно от иллюстраций. Не изменять текст сценария 4.0, а также изображения/сценарии Лизы и Никиты.
3. Показывать изображения без искажения пропорций и без обрезки важных частей (лица, жесты). Адаптивность проверить отдельно на ПК и смартфоне.
4. Все изображения экспортированы в WebP с исходными размерами; никакого искусственного увеличения до 1920 × 1080 не производилось. Для мессенджера с мамой изображение горизонтальное, не вырезать вертикальный кроп автоматически — при необходимости настроить расположение через CSS без удаления важных элементов.
5. История `ilya` пока остаётся тестовым модулем (`pilot`); **не включать full-режим и не менять доступность статистики** без отдельного согласования.
6. Провести тесты, сборку, проверить маршрут Ильи и регрессию остальных историй; не выполнять push, merge или deploy без разрешения.

`MANIFEST.csv` содержит контрольные суммы SHA-256 для проверки целостности каждого файла.
