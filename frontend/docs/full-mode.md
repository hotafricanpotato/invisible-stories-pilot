# Переход выставки в full

> Статистика теперь представлена тремя страницами `/statistics/1`–`/statistics/3`; `/statistics` ведёт на первую. Актуальное описание: [statistics-editorial.md](statistics-editorial.md). Правило доступа после трёх историй сохранено.

Основа: `story-design-system`, `d1651e8`. Переход изменяет доступ и служебные подписи; сценарии, изображения, оформление сцен, материалов, карты и послесловий не меняются.

## Текущий маршрут

Главная → выбор историй → Лиза → выбор → Никита → выбор → Илья → выбор → четыре экрана «Невидимой статистики» → техническое завершение просмотра `/complete`.

`mode: full`, `availableStoryIds: [liza, nikita, ilya]`. Локальный флаг больше не нужен для доступа Ильи. Последовательность определяется полным завершением предыдущей истории. Пройденные истории можно повторно открывать, незавершённые — продолжать с сохранённого этапа/реплики.

После завершения Ильи все карточки имеют статус «Пройдена». Встроенное уведомление: «Все три истории завершены. Теперь доступна „Невидимая статистика“». Кнопка статистики активна, но автоматического перехода нет.

На экране выбора больше нет исключения для двух историй и подписи локального тестирования. Карточка Ильи использует уже утверждённое изображение знакомства, без новой графики или кадрирования. Главная, шапка, подвал и техническое завершение содержат актуальные служебные подписи. Кнопка четвёртого экрана статистики — «Завершить просмотр». Содержание самих четырёх экранов не менялось.

Итоговый тест и эпилог пока не подключены. Их флаги остаются `false`, маршруты и вопросы не создаются. `/complete` не подменяет эти будущие этапы и не обещает их готовность.

## Старые сохранения

Формат состояния остаётся версией 6; ключ `invisible-stories:pilot:v1` и `contentVersion: pilot-1` намеренно сохранены. Название ключа/версии содержания не является правилом доступа. Переименование или смена contentVersion сбросили бы старые сеансы, поэтому не выполняются.

Принимаются старые версии 1–6. Текущие/достигнутые позиции, материалы, ответы карты, завершения Лизы, Никиты и Ильи восстанавливаются по существующим правилам. Состояние статистики (просмотренные экраны, фильтр, объяснения и завершение) сохраняется даже при временной блокировке.

Право доступа вычисляется заново по завершению всех трёх историй. Старые `legacyStatsAccess`, `legacyStoryAccess`, `stats.completed` и `stats.unlocked` не могут открыть статистику сами по себе. Если третья история не завершена, старые адреса `/statistics/1`–`/statistics/4`, `/complete` и сохранённый курсор статистики перенаправляются к выбору. Обработчики продвижения/завершения статистики проверяют то же условие.

После завершения недостающих историй ранее сохранённая статистика снова доступна без потери данных. Ранее завершённые истории остаются доступными для повторного просмотра; частичный прогресс сохраняется до разблокировки.

Сброс с подтверждением очищает состояние и ведёт на главную. На выборе доступна только Лиза, статистика заблокирована. После нового полного прохождения трёх историй она открывается снова. Входной тест не появляется.

## Локальный запуск

В PowerShell из папки `frontend`:

```powershell
npm.cmd run dev
```

Откройте адрес Local. Специальный запуск для Ильи не требуется. Старый `dev:ilya` оставлен совместимым, но уже не меняет доступность историй. Ни одна команда запуска или сборки не публикует сайт.

## Файлы

- `src/content/exhibitionConfig.js` — full и три постоянно включённых модуля.
- `src/state/model.js` — точное уведомление после завершения всех историй; формат сохранений и механики не меняются.
- `src/pages/StorySelection.jsx`, `src/components/StoryCard.jsx` — актуальное условие статистики и готовая карточка Ильи.
- `src/pages/Exhibition.jsx`, `src/main.jsx`, `index.html` — служебные подписи главной/шапки/подвала/завершения, заголовок вкладки и описание страницы.
- `tests/selection.test.js`, `tests/ilya.test.js`, `tests/liza.test.js` — текущие правила и явно выделенные исторические конфигурации пилота.
- `tests/e2e/full.spec.js` — полный маршрут дважды через настоящий интерфейс, сброс, повторный просмотр и миграция старой статистики.
- `tests/e2e/support.js`, `liza.spec.js`, `pilot.spec.js`, `ilya.spec.js`, `selection.spec.js` — адаптация существующих регрессий к трём историям без удаления проверок содержания.
- README и документация — актуальные инструкции; описания предыдущих этапов помечены как исторические.

## Проверки

`npm test`, `npm run test:content`, `npm run build`, `npm run test:e2e`. Дополнительная сборка/набор Ильи: `npm run build:ilya`, `npm run test:e2e:ilya`.

Автоматические тесты проверяют статусы, блокировки URL, сохранённую завершённую статистику пилота, миграции 1–6, частичный Илья, повторный просмотр, сброс и повторное открытие после трёх историй. Браузерные тесты используют production-сборку на десктопном и мобильном профилях; оба полных прохождения выполняются через UI без подстановки флагов завершения. Для миграционных тестов используются отдельно подготовленные старые состояния.

Сценарии и исходные иллюстрации сравниваются с утверждёнными источниками/контрольными суммами. CSS и компоненты историй, источники статистики остаются без изменений относительно `d1651e8`.

Push, merge и публикация не входят в этот этап.

## Результаты реализации

- 40 автоматических тестов — успешно.
- Проверка дословности сценариев и статистики, исходных DOCX и контрольных сумм иллюстраций — успешно.
- 28 основных браузерных проверок и 6 проверок Ильи — успешно, десктопный и мобильный профили Chromium.
- Полный маршрут пройден дважды через UI со сбросом между прохождениями; проверены три статуса «Пройдена», точное уведомление, отсутствие автоперехода, повторный просмотр и повторная разблокировка.
- Старые завершённые состояния статистики сохранены, но доступ к ней и к `/complete` блокируется до завершения третьей истории.
- Обе production-сборки — успешно. Финальная сборка отдельно проверена на актуальные title/description и начальные ограничения выбора.
- Защищённые сценарии, изображения, CSS историй и компонент статистики совпадают с `d1651e8`.

Реальная мобильная визуальная приёмка остаётся за пользователем. Изменения локальные; push, merge и публикация не выполнялись.
