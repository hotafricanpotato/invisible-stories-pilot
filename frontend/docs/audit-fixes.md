## Постоянное сохранение

Новый модуль src/state/persistence.js использует прежний ключ invisible-stories:pilot:v1 и прежнюю модель состояния v6. localStorage — основной источник, sessionStorage — только источник однократного переноса при отсутствии локальной записи. После успешной записи старый ключ из sessionStorage удаляется. При ошибке записи единственная старая копия не удаляется. Существующий localStorage, включая чистую запись после сброса, не заменяется данными старой вкладки. Повреждённый/несовместимый локальный снимок даёт безопасное начальное состояние без импорта устаревшей сессии.

RESET очищает данные текущего сеанса и прежнюю локальную запись, записывает чистое состояние и техническую отметку сброса :reset. Она не является персональными данными и не передаётся в сеть. Проверка отметки перед сохранением и storage-event предотвращают возвращение старого состояния из открытой вкладки. Даже при отсутствии основной записи после сброса старая сессия не импортируется. Остальные ключи браузера не удаляются. Модель разблокировки и сценарные reducer-действия не менялись.

Постоянное сохранение действует для того же origin (домен, протокол, порт). Новые адреса Preview не разделяют localStorage со старым адресом. При блокировке хранилища интерфейс продолжает работать в памяти с существующим предупреждением.

Сценарии историй, вопросы/объяснения итогового теста и эпилог не редактировались.
