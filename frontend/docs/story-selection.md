# Выбор историй и маршрут без входного теста

> Актуализация после финального аудита: прогресс теперь хранится в localStorage с однократной миграцией sessionStorage. Срок хранения больше не ограничен вкладкой. Исторические описания sessionStorage ниже относятся к предыдущим этапам. Подробности: [audit-fixes.md](audit-fixes.md).

> Актуальный режим — `full`: все три истории включены, статистика открывается после всех трёх. Текущие инструкции: [full-mode.md](full-mode.md). Ниже сохранено описание предыдущих этапов пилота.

Рабочая основа: `story-design-system`, `39f495e`. Изменения этого этапа не публикуются автоматически.

## Текущий маршрут

Главная → `/stories` → Лиза → выбор → Никита → выбор → четыре экрана статистики → техническое завершение пилота `/complete`.

Все три карточки видны постоянно. Илья не зарегистрирован как сценарий, его карточка недоступна и подписана «История в разработке». `storyCatalog.js` содержит только имена, названия и темы, без вымышленных сцен.

Входной тест и переходный экран удалены из интерфейса. Их старые URL `/quiz/*` перенаправляются на выбор с заменой записи истории браузера. Данные `initialQuiz.json` и исторические ответы остаются для совместимости; они не влияют на доступ и не используются для вычисления или сравнения баллов.

Статусы: «Доступна», «В процессе», «Пройдена», «Недоступна». Начало истории фиксируется при входе в допустимый этап. Кнопка продолжения восстанавливает `currentStepId` и текущую реплику. Повторный просмотр не сбрасывает достигнутый этап, материалы, карту или завершение.

После первого завершения истории выбор показывает встроенное уведомление, которое можно скрыть. Карточки и статистика используют ту же модель доступа, что и защита URL и reducer. История считается завершённой только после всех существующих обязательных этапов.

## Конфигурация полной версии

В `exhibitionConfig.js`:

- `availableStoryIds` — подключённые утверждённые модули;
- `storyOrder` — Лиза → Никита → Илья;
- `mode` — `pilot` или `full`;
- `statisticsRequiredStoryIds.pilot` — Лиза и Никита;
- `statisticsRequiredStoryIds.full` — все три;
- `finalQuizEnabled` / `epilogueEnabled` — пока `false`; эти модули ещё не реализованы.

После получения сценария Ильи необходимо зарегистрировать его определение, включить в `availableStoryIds` и переключить `mode` в `full`. Компоненты выбора и сцен менять для разблокировки не требуется. Полный режим без подключённого Ильи не открывает статистику. Итоговый тест и эпилог потребуют отдельного утверждённого содержания и реализации; текущие флаги не создают их автоматически.

Под кнопкой статистики показывается только одно условие: для пилота — объяснение исключения после Лизы и Никиты; для полной версии — прохождение всех трёх. Кнопка всегда видна, но отключена до выполнения текущего условия. Автопереходов к статистике нет.

## Миграция

Ключ `invisible-stories:pilot:v1` не изменён. Схема состояния — версия 6, принимаются версии 1–6 с прежней `contentVersion: pilot-1`.

Восстановление истории и статистики больше не зависит от текущего права входа. Сохраняются этапы, текущая/максимальная позиции, материалы, активный материал, ответы карты и завершение; в старой версии 1 ранее показанный текст отмечается прочитанным по прежним правилам. Quiz сохраняется как историческое поле. Старые `legacyStoryAccess` и `legacyStatsAccess` не обходят новые ограничения.

Ранее завершённый Никита доступен для повторного просмотра даже до Лизы. Частично пройденный Никита временно заблокирован, но все его данные остаются; после Лизы он продолжается с сохранённого места. Старые результаты статистики также остаются, даже если теперь раздел временно заблокирован до завершения обеих историй.

«Начать заново» с подтверждением очищает весь прогресс и исторические ответы, возвращает на главную. С главной открывается выбор с доступной Лизой; входной тест не появляется.

Состояние остаётся в `sessionStorage`, без внешней передачи. Переход на другой домен или в другую вкладку не переносит его автоматически.

## Проверки

Из `frontend`: `npm test`, `npm run test:content`, `npm run build`, `npm run test:e2e`.

Проверяются две конфигурации, статусы, реальные условия завершения, уведомления, старые URL, отсутствие теста, миграции 1–4, повторный просмотр, текущая и максимальная позиции, сброс, отсутствие отправки ответов, полный маршрут Лиза → Никита → статистика и размеры от 320 до 1920 px. Браузерные тесты запускают production-пакет в Chromium с десктопным и мобильным профилем.

Исходные сценарии, утверждённые изображения, компоненты/стили сцен, материалы, карта и содержание статистики не редактируются. Изменены только внешняя навигация и служебные подписи маршрута/завершения пилота.

## Техническое подключение Ильи 4.0

Сценарий Ильи теперь зарегистрирован для хранения, но в обычном пилоте доступ выключен. `npm.cmd run dev:ilya` включает его локально после Никиты; условие статистики пилота остаётся прежним. Все зарегистрированные истории хранятся независимо от списка доступных, поэтому выключение локального режима не удаляет данные Ильи. Полный режим ещё не включён. См. [ilya-integration.md](ilya-integration.md).
