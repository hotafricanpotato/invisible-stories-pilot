# Лиза — «Хорошая девочка», сценарий 2.0

Источник: `sources/liza-scenario-2.0.docx` — неизменённый документ пользователя. Извлечённые исходные абзацы и SHA-256 сохранены в `tests/fixtures/liza-v2-source.json`. Сценарные данные: `src/content/liza.json`; оформление и подписи интерфейса: `lizaPresentation.js`.

## Маршрут

Входной тест → существующий технический список историй → Лиза / Никита. Новый экран «Три истории. Три разных дома» не реализован.

`exhibitionConfig.availableStoryIds` задаёт подключённые модули и порядок. Сейчас это Лиза, Никита. Илья не подключён. `storyAccess: "independent"` позволяет отдельно проверять обе истории после входного теста; `"sequential"` включает последовательный доступ. Статистика доступна после завершения всех подключённых историй; `postStoriesPath` и `postStoriesLabel` задают следующий раздел. После добавления третьего утверждённого модуля он войдёт в ту же проверку без изменения компонентов сцен.

Этапы Лизы: знакомство → после выступления → другие планы → всё нормально → 3 материала → карта → образовательное объяснение → последняя сцена → финальный текст. Реплики живого диалога идут по одной. Переписка — отдельный целый фрагмент. Повествование и мысли сохраняют свою позицию. Последняя публикация в альбоме представлена текстом, без выдуманной третьей фотографии.

## Состояние

Версия 4, прежние `contentVersion` и ключ sessionStorage сохранены. Состояние находится в `stories.liza` и `stories.nikita`. Восстанавливаются версии 1–3: сохраняются текущая/достигнутая позиция Никиты, материалы, ответы карты, статистика и адрес продолжения. `legacyStoryAccess` сохраняет прежний доступ к Никите; `legacyStatsAccess` сохраняет доступ к статистике уже завершённого старого пилота. Эти признаки сбрасываются действием «Начать заново». Новое прохождение требует завершения обеих доступных историй перед статистикой. Данные не передаются внешним сервисам.

## Графика, которая ещё требуется

Все отсутствующие изображения обозначены нейтральной временной заглушкой. DRAFT-файлы и изображения из интернета не используются. Существующие художественные кандидаты не объявлены финальными ассетами.

| --- | --- | --- |
| Знакомство / переписка | Лиза с телефоном, обычная домашняя обстановка, танцы и фотография как детали | WebP от 1200×1500; возможен ранее переданный отдельный портрет после назначения |
| После выступления | Мама встречает Лизу с цветами у раздевалки, забота и неоднозначность реакции | WebP 1920×1080 и согласованная мобильная композиция около 1080×1200 |
| Другие планы | Кухня, фотографии, чашка чая, Лиза и мама | Те же размеры; прежний кухонный кандидат требует проверки реквизита |

Все семейные изображения должны выглядеть как связанный архив разных лет. Мама — заботливый человек, который одновременно оказывает эмоциональное давление. Не добавлять заявку в фотокружок, открытый конфликт или иные отсутствующие действия.

## Проверка

`npm test`, `npm run test:content`, `npm run build`, `npm run test:e2e` из frontend. Новые тесты проверяют дословный перенос из DOCX, ключи B/C/A, завершающие этапы, независимость прогресса, миграции и обе конфигурации доступа. Браузерные проверки включают Лизу целиком, регрессию Никиты, вложенные URL, перезагрузку и мобильные размеры.

Для локального просмотра: `npm.cmd ci`, затем `npm.cmd run dev` в frontend. Для проверки независимости откройте любую из двух историй в техническом списке после теста. Preview не обновится до отдельно разрешённых push и развёртывания. Итоговый тест, история Ильи и новый дизайн статистики не реализованы.

## Служебные подписи

Обновлены только устаревшие общие сообщения о количестве доступных историй на главной, в техническом списке и подвале; конечный переход выбирает следующую незавершённую историю из реестра. Служебные номера Никиты обновлены с 01 на 02 в соответствии с согласованным порядком историй. Его сценарные тексты, иллюстрации, стили и механики не менялись.
